## 1. Speech Emotion Recognition (SER)

A **Speech Emotion Recognition** project focused on identifying emotions from human speech using **Deep Learning and audio processing techniques**.

The project explores how speech signals can be processed and transformed into meaningful representations that can be used for emotion classification.

### Key Areas

* Audio data preprocessing
* Feature extraction
* Speech representation
* Deep Learning
* Model training
* Emotion classification
* Model evaluation

### Models & Technologies

* Python
* TensorFlow / Keras
* Hugging Face
* Wav2Vec2
* HuBERT
* XLS-R
* NumPy
* Pandas
* Scikit-learn
